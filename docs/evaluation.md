# Evaluation: VADER sentiment vs. star ratings

Generated by `python scripts/evaluate.py` from `data/sample/reviews.jsonl` (10,755 All_Beauty reviews). Re-run it after changing `analyzer/nltk_layer.py`.

## Setup
- **Prediction:** NLTK 3.9.4 VADER `compound` on the review text, through `analyzer/nltk_layer.py` (the same code the build and the browser run). Labels: positive >= 0.05, negative <= -0.05, otherwise neutral (VADER README thresholds).
- **Weak gold labels from stars:** 1-2 stars = negative, 3 = neutral, 4-5 = positive. Stars are a *proxy* for the sentiment of the text, not a human sentiment annotation.
- **Headline metric: macro-F1**, because the classes are imbalanced: 1 star 1,340, 2 star 619, 3 star 809, 4 star 1,154, 5 star 6,833.

## Reading the numbers
- VADER is strong on clear praise: positive recall is 87.4%.
- It is weaker on complaints: only 49.5% of 1-2 star reviews are scored negative. Many complaints are factual descriptions of a defect or a return, with few lexicon words.
- The neutral class is the hardest (F1 0.113): 3-star reviews are usually mixed ("nice color, but it chips"), and VADER sums them to a clearly positive or negative compound.
- The small domain lexicon in `nltk_layer.DOMAIN_LEXICON` (e.g. flimsy, greasy, sticky, overpriced; never overriding VADER's own ratings) changes macro-F1 from 0.500 to 0.507.

Typical causes: negative words describing the *problem the product solved* ("my dying, dull and unimpressive looking hair"), sarcasm and disappointment phrased politely ("I wanted to love it"), domain phrases VADER does not know ("runs small", "broke me out"), and reviews where the stars disagree with the text.

## NLP correctness review (spaCy + NLTK)
- **Shared code:** the playground imports the same `nltk_layer.py`. The Playwright test `tests/e2e/test_site.py::test_playground_matches_build_scores` checks that Pyodide 314.0.8 returns the same compound as the build (|diff| <= 1e-4) for the examples in `site/data/nltk_examples.json`.
- **Stopwords:** removed only for FreqDist and collocations, never before VADER. Negations stay in the vocabulary, so complaint phrases such as "not worth", "not work" and "stop work" appear among the negative collocations.
- **Collocations:** bigrams are counted inside sentences (`from_documents`), with a frequency filter (5 for the category, 3 per product) and the likelihood-ratio measure, so rare pairs do not dominate as they do with PMI.
- **Aspects:** the spaCy rules (amod, acomp + nsubj, opinion verb + dobj, conj, neg) are checked on golden sentences in `tests/test_spacy_layer.py`. Known gaps: the small model mislabels some entities (e.g. "polish" as NORP, "Norelco" as GPE), and adjectives that describe a type rather than an opinion are only partly filtered (`NON_OPINION_ADJ`).
- **Not done:** a hand-labeled set of about 100 aspect-opinion triples to measure extraction precision (and inter-annotator kappa). That needs human annotators, so it is listed as future work.

## Limitations
- VADER is a lexicon and rule model "specifically attuned to sentiments expressed in social media" (VADER README). It handles negation, boosters, capitals, punctuation and emoji, but not sarcasm or most domain-specific phrasing.
- Star ratings are a weak proxy for the sentiment of the text.
- "Sales" metrics are proxies (rating counts and review velocity), not revenue. No simulated sales data is used.
- The sample (200 products, up to 60 reviews each) over-represents popular products by design.
- spaCy analysis runs only at build time. Live analysis in the browser uses NLTK alone.
- Amazon Reviews 2023 declares no license, so it is used for academic, non-commercial work only (Hou et al. 2024, arXiv:2403.03952).
